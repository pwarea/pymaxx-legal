What to include

A complete report saves a lot of back and forth. Please include:

  • your device model;
  • your iOS or iPadOS version;
  • the Pymaxx version, as shown in the App Store;
  • what you did, what you expected and what happened instead;
  • the steps to make it happen again;
  • for a problem with running code, the error message from the console and a short code sample that shows the problem.

Please do not send API keys, passwords or code you want to keep private. A small test snippet written just to show the problem is almost always enough.

Privacy requests

For privacy questions and requests, you can use the subject "Pymaxx Privacy". Pymaxx keeps your data on your device, so you can handle most requests yourself in the app. See Controlling and deleting your data in the Privacy Policy.

Security problems

If you think you have found a security problem, please email us at the address above instead of posting the details publicly.

Common questions

Does Pymaxx work offline?

Yes. Python, JavaScript, TypeScript, SQL and all bundled libraries are part of the app, so nothing needs to be downloaded before you run code. You only need a connection to download a local AI model or to use an external AI provider. Downloaded models and Apple's on-device model work offline. A file kept only in iCloud may be unavailable until iCloud can download it.

Where are my projects stored?

On your device. Each project you create in Pymaxx is a folder in On My iPhone (or On My iPad) › Pymaxx in the Files app, and Pymaxx keeps its version history and Recently deleted in the app's own storage. If you opened a project from another place in the Files app, saving writes back to the original file, and iCloud or another provider may sync it. Deleting Pymaxx removes its own storage, including that Pymaxx folder, but not originals elsewhere in Files or iCloud and not files you exported.

How do I delete a project?

Choose Move to trash. The project goes to Recently deleted, where you can restore it or choose Permanently delete. Permanent deletion also removes the project's history, its Local Git repository and the photos in its chats, but not its folder in the Files app: delete that folder in Files if you no longer need it.

If you delete, rename or move a project's folder in On My iPhone (or On My iPad) › Pymaxx in the Files app, Pymaxx tells you when you open the project. If you only renamed or moved it, put it back and open the project again. Otherwise choose Restore files to put the latest version back from Pymaxx's saved history, or Remove from Pymaxx to move the project to Recently deleted.

How do I delete a downloaded model?

Go to Settings → Network & AI → Local AI models and delete the model.

How do I remove an API key?

Go to Settings → Network & AI → API profiles and delete the profile. This removes the key from the iOS Keychain. Do this before you uninstall the app, because removing the app may not clear Keychain data.

Why won't my file run?

Check these first:

  • Pymaxx runs Python, JavaScript, TypeScript and SQL files.
  • Python can import only the libraries that come with the app, including NumPy, Matplotlib, Pillow, pandas, SymPy, NetworkX, SciPy, scikit-learn and pytest. pip and micropip are not available, and Pymaxx cannot install packages. If a project contains a pymaxx-packages.json file, Pymaxx keeps it as an ordinary file and does not install anything listed in it.
  • JavaScript and TypeScript can import only .js, .mjs and .ts files from the same project. npm packages, Node APIs and imports from URLs do not work.
  • Subprocesses, shell commands, raw sockets, local servers, full threading and virtual environments are not available, and neither are native extension packages other than the ones that come with the app.
  • Pymaxx gives your code no internet access.
  • Very large files and projects can reach the app's size limits. When that happens, the app tells you which limit was reached.
  • SQL runs against a new, empty SQLite database every time, so create the tables you need in the same file.

If it still fails, send us the console message and a short example.

My Python code wrote a file. Where is it?

Python runs on a temporary copy of the project. Files your code writes appear in Generated files. Choose Save to project there to keep them.

Does the AI assistant send my code anywhere?

Not with on-device models. With an external provider, only after you turn on network access, the profile passes its connection test and you allow sharing for that project and profile. From then on, each message you send goes to the provider together with any photos you attached, recent messages from the chat and the files checked in Context. The Privacy Policy has the details.

How do I stop sending data to a provider?

Withdraw the permission in the chat's sharing details, or turn off Allow network access in Settings → Network & AI. Content the provider already received stays with that provider, so ask the provider if you want it deleted.
